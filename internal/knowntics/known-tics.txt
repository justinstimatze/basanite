# known-tics — words and phrases Claude is known to lean on. This is the
# *starter seed*: on first run it is copied to ~/.config/basanite/known-tics.txt,
# and from then on that file is the only one read — it's yours to curate. Add
# your own leans; delete ones that stop mattering (a model's tells age out).
# Nothing here is re-applied over your edits.
#
# It ships as a conservative, high-precision sample of the globally common
# leans, biased toward the ones that recur in Claude Code transcripts.
#
# Every entry left here has been observed firing. An earlier seed also carried
# the folklore leans — the iconic phrases everyone quotes, taken from the
# community "Claude Bingo" card — and `basanite audit` found that not one of
# them occurred anywhere in months of real transcripts. Folklore about a
# model's register turns out not to be evidence about it. Add your own freely,
# then audit them.
#
# Format mirrors proper-nouns.txt: one entry per line, '#' comments, blank
# lines ignored. A line with a space is a phrase, matched verbatim against the
# surface word stream; anything else is a single word, lemmatized to match
# corpus tokens.
#
# These are a *reference*, not a denylist: a seeded entry still has to be
# something you're actually leaning on now (steady rate, dispersed) before it
# surfaces, and the output stays awareness, never prohibition.
